rationale:
  - The approved HTML mockup was a visual oracle, not an acceptable runtime implementation. The feature therefore uses typed React components and existing domain modules while preserving the approved geometry and presentation.
  - Routing follows the repository's static-hosting convention: the application recognizes both logical `/stage` and deployed `/uiadapt_demo/stage/`; the build creates a physical nested entry because `serve` is not configured for SPA fallback.
  - The canonical replay event payloads do not reach the required stage transitions at the approved presentation timestamps when consumed at their original wall-clock offsets. The chosen design reschedules delivery only; every canonical event object is delivered unchanged and in order to the existing reducer.

  - SSIM tooling adds only development dependencies (`pngjs`, `ssim.js`). No new runtime dependency or external asset request was introduced.

implementation:
  core_logic: `snapshotAt(elapsedMs)` clamps time, replays unchanged `REPLAY_EVENTS` in order through `runtimeReducer`, and returns the resulting `RuntimeSnapshot`. Its loop is O(n) time for n replay events and O(1) auxiliary space beyond reducer snapshots; n is currently 48.
  data_flow: elapsed time or key checkpoint -> `useStageController` -> `snapshotAt` -> canonical replay events -> runtime reducer -> Stage presentation mapping and domain-backed product components -> DOM audit attributes.
  state_transition: Playback uses IDLE -> RUNNING -> PAUSED or COMPLETED, with reset to IDLE. Domain presentation checkpoints are EXPLORE at 3000 ms, COMPARE at 12000 ms, and PURCHASE_INTENT at 20000 ms; keyboard keys 1/2/3 enter the corresponding paused checkpoints.
  edge_conditions: Elapsed time is clamped to 0..27000 ms; NaN becomes 0; repeated play while RUNNING is ignored; play after COMPLETED resets time; timers and animation frames are cleaned up; fullscreen rejection is swallowed because denial does not alter Stage state.
  error_handling: Stage evidence generation fails closed on wrong Chrome version, wrong dimensions, external requests, console/page errors, invalid video, or SSIM below threshold. Failed runs retain heatmaps/diagnostics and do not overwrite passing evidence.
  I/O: Browser reads only the same-origin static bundle and self-hosted fonts. Evidence tooling writes three PNGs, one WebM, two JSON reports, and failure heatmaps when applicable.
  API_contract: none; no endpoint was added or changed.
  DB_contract: none; Stage does not read or write MySQL.
  persistence: none; playback and state are in-memory for the current page lifetime.
